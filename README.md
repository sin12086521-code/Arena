# Mental Arena — 온라인 1:1 암산 배틀

## 로컬 실행
1. Node.js 18 이상 설치
2. 프로젝트 폴더에서 `npm install`
3. `npm start`
4. `http://localhost:3000` 접속

## 친구와 대결
두 사람이 동일한 서버 주소로 접속해야 합니다. 한 명이 방을 만들고 5자리 코드를 공유합니다. 두 명 모두 입장해 준비 완료를 누르면 동일한 문제가 양쪽 화면에 동시에 출제됩니다. 먼저 정답을 맞힌 사람이 1점을 얻고, 다음 공통 문제가 출제됩니다. 제한 시간은 120초입니다.

## 인터넷에서 플레이하려면
이 프로젝트에는 실시간 통신 서버(Socket.IO)가 포함되어 있습니다. 서로 다른 네트워크의 친구와 플레이하려면 이 Node.js 프로젝트를 인터넷에 배포하고 배포된 주소를 공유해야 합니다. HTML 파일만 열어서는 온라인 대결이 작동하지 않습니다.
